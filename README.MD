# Python Programming Projects

**A Collection of Basic Python Programs**

## 📌 Project Description

This project contains three basic Python programs developed to demonstrate fundamental programming concepts and the conversion of C programs into Python.

The project includes programs for calculating the factorial of a number, generating the Fibonacci series, and implementing a Student Class using Object-Oriented Programming (OOP) concepts.

It is designed to strengthen programming fundamentals, logical thinking, and understanding of Python syntax.

## ✨ Features

- **Factorial Program:** Calculates the factorial of a given non-negative integer using a loop.
- **Fibonacci Series:** Generates the Fibonacci sequence up to the specified number of terms.
- **Student Class Program:** Demonstrates Object-Oriented Programming using a Student class with attributes and methods.
- Simple and beginner-friendly Python code.
- Easy to understand and execute.

## ▶️ How to Run the Programs

### 1. Factorial Program

**File Name:** `factorial.py`

**Description:** Calculates the factorial of a given number.

**Command:**

```bash
python factorial.py
```

**Sample Output:**

```text
Enter a number: 5
Factorial of 5 is: 120
```

### 2. Fibonacci Series Program

**File Name:** `fibonacci.py`

**Description:** Generates the Fibonacci series for the specified number of terms.

**Command:**

```bash
python fibonacci.py
```

**Sample Output:**

```text
Enter the number of terms: 7
Fibonacci Series:
0 1 1 2 3 5 8
```

### 3. Student Class Program

**File Name:** `student.py`

**Description:** Demonstrates the concept of classes and objects in Python. It uses a Student class to store and display student information such as name, roll number, and marks.

**Command:**

```bash
python student.py
```

**Sample Output:**

```text
Student Details:
Name: Sourav
Roll Number: 101
Marks: 89
```
